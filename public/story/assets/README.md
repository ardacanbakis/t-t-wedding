# Story site assets

The timeline site (`/story`) expects these images in this folder — copy them
over from the original Claude design project:

- `hecate.jpeg` — Chapter 4 photo
- `didi.jpeg` — Chapter 6 photo
- `invitation.png` — the invitation poster (Chapter 9)

Also: if your original project has a `.image-slots.state.json` sidecar (it
stores the photos you dropped into the empty slots), copy it into
`public/story/` so those photos show up here too.
